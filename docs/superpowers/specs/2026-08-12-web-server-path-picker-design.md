# Web 服务端路径选择器设计

## 目标

简化 Web 界面的文件和目录发送入口。删除浏览器上传文件、上传目录和粘贴图片功能，只保留由 `feiq-cli` 所在电脑选择并发送本机路径的方式。用户既可浏览允许目录，也可手动输入路径。

## 配置

在现有严格 JSON 配置中新增可选字段：

```json
{
  "web_roots": ["~/", "/Volumes/data"]
}
```

- 未设置或数组为空时，默认只允许当前用户的 `$HOME`。
- 每个值必须是已存在的目录。
- 支持 `~` 和 `~/...`，加载配置时转换为当前电脑的 Home 目录。
- 支持多个互不包含的根目录。
- 明确配置 `"/"` 时，允许浏览和选择整个文件系统。
- 去除重复项，并将被更宽根目录包含的项合并。例如同时配置 `/` 和 `~/` 时只保留 `/`。
- 配置中的非法路径会阻止程序启动，并返回指出具体路径的错误。

`config.example.json` 和根 README 同步展示该字段及风险。配置 `/` 会把整台电脑上的可读文件暴露给本机 Web 操作者；使用 `--allow-remote` 时风险会扩展到可访问 HTTP 端口的局域网设备。

## 服务端接口与安全边界

新增只读接口：

```text
GET /api/paths?path=<absolute-or-home-path>
```

响应包含：

- 当前规范化目录路径；
- 当前路径所属的允许根目录；
- 可切换的允许根目录列表；
- 父目录（仅在仍处于允许根目录时提供）；
- 当前目录下可读的普通文件和目录，目录优先、名称排序；
- 每项的名称、完整路径、类型和文件大小。

浏览接口不读取文件内容。不可读条目可从结果中忽略；当前目录不存在、不是目录或越过授权范围时返回明确的 4xx 错误。

`POST /api/send-path` 同样执行授权校验。手动输入路径不能绕过 `web_roots`。校验使用绝对路径、清理后的路径和符号链接解析后的真实路径，防止 `..` 或位于授权目录内的符号链接跳到授权目录之外。待发送目标必须是普通文件或目录。

保留现有同源检查、安全响应头、默认仅监听 `127.0.0.1:2426` 以及显式 `--allow-remote` 限制。删除不再使用的 `POST /api/upload` 与临时上传处理代码。

## Web 交互

聊天输入区只保留消息文本框和“发送”按钮，不再显示“文件”“目录”按钮，也不再拦截粘贴图片。

聊天标题栏保留“选择本机路径”入口。打开后显示路径选择器：

1. 顶部根目录选择框可在 `web_roots` 间切换。
2. 面包屑只展示当前允许根目录内部层级，不能向上越界。
3. 目录列表中双击或点击进入按钮可进入目录。
4. 单击文件选中文件；处于“发送目录”模式时可选择当前目录或列表中的子目录。
5. 类型可在“文件”和“目录”之间切换。
6. 保留手动路径输入，输入 `~/...` 或绝对路径后可定位/选择；服务端负责最终授权校验。
7. 发送前显示选中路径，发送成功后关闭选择器；错误显示在现有通知区域。

选择器沿用现有深色视觉样式，并适配桌面、中等宽度、手机宽度和低高度窗口。文件列表独立滚动，避免挤压消息输入区。

## 代码边界

- `cmd/feiq-cli/config.go`：解析和验证 `web_roots`。
- `cmd/feiq-cli/api.go`：授权根目录、路径规范化、目录枚举和发送前校验。
- `web/src/App.vue`：路径选择器状态与请求流程，移除浏览器上传逻辑。
- `web/src/style.css`：响应式选择器布局。
- `web/dist`：由 `npm run build` 生成并嵌入 Go 二进制。

不修改 `ipmsg` 协议层。选择完成后仍调用已有的 `SendPath` 发送文件或目录。

## 测试与验收

Go 测试先覆盖以下行为：

- 默认根目录为 `$HOME`；
- 配置展开 `~/`，允许显式 `/`，拒绝不存在或非目录路径；
- 浏览正常目录并按目录优先排序；
- 拒绝 `..`、未授权绝对路径和越界符号链接；
- `/api/send-path` 拒绝授权范围外的手动路径；
- 配置 `/` 时可选择文件系统中的路径。

前端执行 TypeScript 类型检查和生产构建；Go 执行完整 race 测试、`go vet`、格式检查和交叉编译。构建后验证 `web/dist` 与源码一致。

验收结果：默认启动只能查看 `$HOME`；配置更多目录后可以切换浏览；配置 `/` 后可以从根目录浏览；UI 不再出现浏览器文件/目录上传按钮；选择服务端文件或目录后能够走现有传输流程。
